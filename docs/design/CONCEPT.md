# Loond 비주얼·IA 컨셉 (2026-09-16)

기준 목업: `loond-concept-mockup.png`

## 분위기
- 밝은 로컬 발견 앱 (정부/보고서 UI 지양)
- 라운드 카드, 여백, 히어로·썸네일 이미지
- 시드: 소프트 블루 + 포인트 오렌지/그린/퍼플 카테고리

## IA (목업 기준)
하단 탭 4:
1. **홈** — 지역칩, 히어로, 카테고리 퀵아이콘, NOW 신청, 곧 시작(가로 스크롤)
2. **발견** — 검색+칩(전체/관광/맛집/코스), 이미지 카드 리스트
3. **내 기회** — 맞춤 혜택·관심 키워드(얇게 시작, 키워드는 UI만 가능)
4. **더보기** — 설정·개인정보·지역 변경 등

## 데이터 매핑
| 목업 | 기존 타입 |
|------|-----------|
| NOW 신청 / 신청하기 | APPLY |
| 곧 시작·행사 | ENJOY |
| 발견(관광·맛·코스) | DISCOVER |
| 내 기회·혜택 | BENEFIT (얇게) + 도 단위는 이후 |

## 진입
- 시군 긴 나열 ❌ → 검색 + 인기/최근 칩
- 도 혜택은 홈/내기회에 배지·섹션으로 확장 여지

## 유지
원문 CTA, Hard Sort·만료 제외, AdMob 규칙, 출처 신뢰
