# 내 기회 · 맞춤 설정 화면 초안 (2026-09-21)

진입: **내 기회** → 「맞춤 혜택」카드 CTA **「맞춤 조건 설정」**  
저장: 기기 로컬만 (`SharedPreferences` / 이후 secure storage). 서버·계정 없음(현 방침 유지).

## 목적
BENEFIT·APPLY 후보를 **과하게 숨기지 않고** 우선순위를 올리기 위한 힌트 프로필.  
실제 수급 여부는 원문·공식 창구 기준(앱은 안내).

## 정보 구조

### 1. 나
| 필드 | 필수 | UI | 매칭 용도 |
|------|------|-----|-----------|
| 출생연도 | 권장 | 연도 피커 (또는 연령대 칩) | 청년/어르신/연령 제한 공고 |
| 성별 | 선택 | 선택 안 함 / 여 / 남 | 일부 대상 공고(드묾) — 기본 숨김 가능 |

### 2. 사는 곳
| 필드 | 필수 | UI | 매칭 용도 |
|------|------|-----|-----------|
| 시 | 예 | 기존 지역 선택과 연동 | 시 단위 사업 |
| 구 | 권장 | 수원 구 칩/피커 | 구 사업·주민센터 권역 |
| 동 | 권장 | 검색+목록 | 동 단위·초근접 공고 |

앱 전역 `Region`과 맞추되, **동은 맞춤 프로필 전용**으로 두어도 됨(피드 전체를 동으로 좁히지 않음).

### 3. 아이 (핵심 추가)
| 필드 | 필수 | UI | 매칭 용도 |
|------|------|-----|-----------|
| 아이 있음 | 선택 | 스위치 | 육아·아동 혜택 노출 |
| 아이 나이대 | 아이 있음 ON 시 | 다중 칩 | 연령별 사업 분기 |

**나이대 칩 (복수 선택)**  
- 임신·예정 (본인/배우자 임신 — 아이 전 단계)  
- 영아 0–2세  
- 유아 3–5세  
- 초등 6–12세  
- 청소년 13–18세  

카피: 「여러 명이면 해당 나이대를 모두 골라 주세요.」  
정확한 생년월일까지는 **1차에 넣지 않음**(입력 부담·민감도↓). 나중에 “아이별 출생연도”로 확장 가능.

### 4. 상황 태그 (선택, 복수)
청년 · 구직 · 재직 · 신혼·예비 · 임신·육아 · 1인가구 · 어르신 · 창업  

「결혼 여부」 단독 Y/N 대신 **신혼·예비 / 임신·육아** 태그로 커버.

### 5. 관심 키워드
기존 내 기회 칩과 동일 소스(청년·창업·문화…). 맞춤 설정과 동기화.

## 화면 플로우
1. 내 기회 → 맞춤 혜택 영역  
   - 조건 없음: 「나이·동네·아이 조건을 넣으면 맞는 혜택을 먼저 보여 드려요」+ 버튼  
   - 조건 있음: 요약 칩(예: 30대 · 원천동 · 영아) + 「수정」
2. 맞춤 설정 폼 → 저장하고 혜택 보기 → 필터/정렬된 목록
3. 더보기/설정에서도 「맞춤 조건」 진입 가능

## 매칭 규칙 (초안)
- **하드 제외**: 명백히 충돌하는 연령·지역만(데이터에 구조화 필드가 있을 때)
- **소프트 가산**: 아이 나이대·상황 태그·키워드 일치 시 상단 노출
- BENEFIT 시드가 없을 때는 APPLY/안내 카드 + 「복지로·보조금24에서 더 보기」딥링크

## 개인정보·카피
- 상단 고정: 「혜택 추천에만 쓰고, 기기에만 저장해요.」
- 면책: 정부 수급 심사가 아님 / 원문 확인 고지(기존 정책 문구와 정합)

## 비범위 (1차)
- 소득·재산 구간 입력
- 주민번호·본인인증
- 가족 구성원별 상세 프로필
- 서버 동기화

## 구현 메모
- 모델 예: `BenefitProfile { birthYear?, gender?, sigungu?, dong?, hasChild, childAgeBands[], situationTags[], keywords[] }`
- `MyChanceTab` CTA → 새 `BenefitProfileScreen`
- published BENEFIT 보강 전에도 APPLY `target` 텍스트 휴리스틱(영유아/초등/아동수당 등)으로 데모 가능

## 구현 상태 (2026-09-21)
