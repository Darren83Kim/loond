### 데이터 보안 · 광고 선언 (Play Console, 수동)

0.1.10 릴리스는 광고를 포함한다. 콘솔 **앱 콘텐츠 → 데이터 보안**과 **광고** 선언을 이 빌드와 같게 저장한다. Google의 현재 GMA SDK 공개 항목을 우선하고, 아래는 이 앱 코드 기준의 최소 항목이다.

- **광고 ID** (기기 또는 기타 ID): 수집됨 · 제3자(Google AdMob)와 **공유** · 목적: 광고. 앱이 자사 서버로 보내지 않음.
- **앱 상호작용** (앱 활동): 광고 노출·클릭. Google AdMob과 공유 · 목적: 광고.
- **진단 정보** (앱 정보 및 성능): 비정상 종료 로그·진단. AdMob SDK가 보낼 수 있음 · Google과 공유 · 목적: 분석/광고(콘솔 선택지는 Google 공개 문구에 맞출 것).
- **위치**: 앱은 위치 권한을 요청하지 않는다. 대략적 위치를 앱 수집으로 추가하지 않는다. AdMob 자동 공개에 IP 기반 항목이 있으면 그 문구를 따른다.
- **계정·이름·이메일**: 수집하지 않음. 북마크·지역·혜택 조건은 기기에만 있음(전송하지 않으면 수집으로 선언하지 않음).
- 전송 중 암호화: 예 (HTTPS 피드, Google SDK).
- 사용자가 계정 삭제를 요청하는 절차: 계정이 없음. 광고 ID 재설정은 Android 설정.
- 개인정보처리방침 URL은 앱 설정 링크와 같다.  
  `https://github.com/Darren83Kim/loond/blob/main/docs/legal/privacy-policy.md`

### app-ads.txt (개발자 웹사이트, 수동)

AdMob이 보여주는 문구를 확인해 개발자 웹사이트 **루트**에 둔다. 앱 ID의 게시자 번호 기준 예상 한 줄:

```
google.com, pub-8022343674155817, DIRECT, f08c47fec0942fa0
```

호스트는 Play Console / AdMob에 등록된 개발자 웹사이트다 (`https://<그 도메인>/app-ads.txt`). 이 저장소의 GitHub Pages(`darren83kim.github.io/loond/`)가 그 웹사이트인지는 콘솔 설정을 봐야 한다. 도메인이 없으면 콘솔에 사이트를 정한 뒤 그 루트에 파일을 둔다.
