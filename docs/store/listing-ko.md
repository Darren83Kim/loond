# 로온드 — 스토어 리스팅 초안 (한국어)

## 앱 이름
**로온드**

## Play 앱 만들기 필드
- 패키지 이름: `com.loond.loond` (변경 불가 · applicationId와 동일)
- 기본 언어: 한국어(ko-KR)
- 앱 / 무료
- 그래픽: `docs/store/play/icon-512.png`, `feature-graphic.png`
- 스크린샷: `docs/store/screenshots/phone/`


## 짧은 설명 (≈80자 이내)
수원 등 지역 공고·행사를 모아 보는 비공식 안내. 회원가입 없이 공식 원문으로 이동.

## 긴 설명
로온드는 수원(수원특례시) 등 지역의 공공·지역 기회를 **신청(APPLY) · 즐기기(ENJOY) · 발견(DISCOVER)** 으로 정리해 보여주는 비공식 안내 앱입니다.

**이런 분께 맞춰요**
- 신청 마감이 가까운 공고를 빠르게 보고 싶을 때
- 주말에 즐길 행사·관광 정보를 한 목록에서 보고 싶을 때
- 회원가입·점수·복잡한 알림 없이 원문만 확인하고 싶을 때

**주요 기능**
- NOW: 지금 신청·참여 가능한 기회
- ANYTIME: 언제든 둘러보는 발견 콘텐츠
- 상세에서 일정·요약·출처를 확인한 뒤 **공식 원문 보기**로 이동
- 신청 마감이 지난 공고는 목록에서 제외 (데이터에는 남을 수 있음)

**정보 출처**
- 항목마다 공식 원문 URL(예: 지자체·공공기관 웹사이트)로 바로 이동합니다.
- 대표 출처 예시: https://www.suwon.go.kr (수원특례시), https://korean.visitkorea.or.kr (한국관광공사 TourAPI 연계 정보)
- 그 외 성남·고양 등 지자체 고시/공고 원문은 각 항목의 공식 링크를 따릅니다.

**면책(중요)**
본 앱은 정부기관을 대표하거나 정부기관과 제휴·위탁 운영하지 않습니다. 공고·행사·관광 정보는 각 공식 출처를 모아 안내할 뿐이며, 일정·자격·접수 방법·법적 효력은 반드시 해당 공식 원문에서 확인하세요.

**기타**
- 광고(AdMob)가 표시될 수 있습니다.
- 개인정보처리방침: 앱 설정 또는 배포 시 고지 URL

문의: contact@loond.example (플레이스홀더)

- [ ] APPLY 비어 있을 때 empty 카피 (“지금 신청 가능한 공고가 없어요”) — 가능하면
- [ ] 상세 화면 — 제목, D-Day, 원문 버튼
- [ ] 설정 — 개인정보 처리방침 / 출처 안내
- [ ] (선택) 하단 배너 광고 영역 — 테스트 광고여도 레이아웃만 확인
- [ ] 가로·세로 비율·스토어 권장 해상도 준수 (Play/App Store 가이드)

### 촬영 팁 (내부)
- 기기: Android 실기기 또는 에뮬레이터 (권장 해상도 Phone: 1080×1920 이상).
- APPLY 카드가 적을 때: published에 마감 임박 공고가 있으면 D-Day가 잘 보임.
- Empty APPLY: fixture/`applySorted`가 비고 ENJOY만 있는 빌드로 촬영하거나, 위젯 테스트 카피로 대체 캡처.
- 원문 버튼·설정 링크는 실제 외부 URL이 열리므로 스크린샷 직후 뒤로가기로 복귀.
