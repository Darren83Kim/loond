# 로온드 — 스토어 리스팅 초안 (한국어)

## 앱 이름
**로온드**

## 짧은 설명 (≈80자 이내)
수원의 신청·행사·발견 기회를 한곳에서. 회원가입 없이 원문으로 바로 확인.

## 긴 설명
로온드는 수원(수원특례시)의 공공·지역 기회를 **신청(APPLY) · 즐기기(ENJOY) · 발견(DISCOVER)** 으로 정리해 보여주는 앱입니다.

**이런 분께 맞춰요**
- 신청 마감이 가까운 공고를 빠르게 보고 싶을 때
- 주말에 즐길 행사·관광 정보를 한 목록에서 보고 싶을 때
- 회원가입·점수·복잡한 알림 없이 원문만 확인하고 싶을 때

**주요 기능**
- NOW: 지금 신청·참여 가능한 기회
- ANYTIME: 언제든 둘러보는 발견 콘텐츠
- 상세에서 일정·요약·출처 확인 후 **원문 바로가기**
- 신청 마감이 지난 공고는 목록에서 제외 (데이터에는 남을 수 있음)

**안내**
- 일정·자격·접수 방법은 반드시 **원문(공식 출처)** 에서 확인하세요.
- 광고(AdMob)가 표시될 수 있습니다.
- 개인정보처리방침: 앱 설정 또는 배포 시 고지 URL

문의: contact@loond.example (플레이스홀더)

## 키워드 (초안)
수원, 수원특례시, 공고, 신청, 행사, 축제, 관광, 청년, 시민, 공공, 모집, 로온드, loond, 기회, 문화

## 카테고리 제안
라이프스타일 / 뉴스 및 잡지 / 여행 및 지역정보 (스토어 정책에 맞게 1개 선택)

## 스크린샷 체크리스트
- [ ] 홈 NOW — APPLY 섹션(카드 2장 이상, D-Day 라벨 보임)
- [ ] 홈 ENJOY 또는 DISCOVER 섹션
- [ ] APPLY 비어 있을 때 empty 카피 (“지금 신청 가능한 공고가 없어요”) — 가능하면
- [ ] 상세 화면 — 제목, D-Day, 원문 버튼
- [ ] 설정 — 개인정보 처리방침 / 출처 안내
- [ ] (선택) 하단 배너 광고 영역 — 테스트 광고여도 레이아웃만 확인
- [ ] 가로·세로 비율·스토어 권장 해상도 준수 (Play/App Store 가이드)

### 촬영 팁 (내부)
- 기기: Android 실기기 또는 에뮬레이터 (권장 해상도 Phone: 1080×1920 이상).
- APPLY 카드가 적을 때: published에 마감 임박 공고가 있으면 D-Day가 잘 보임.
- Empty APPLY: fixture/`applySorted`가 비고 ENJOY만 있는 빌드로 촬영하거나, 위젯 테스트 카피로 대체 캡처.
- 원문 버튼·설정 링크는 실제 외부 URL이 열리므로 스크린샷 직후 뒤로가기로 복귀.
